# 검증

## 1. 자동 검사 (모두 통과해야 완료)

```bash
pnpm lint        # feature 경계 규칙 포함
pnpm typecheck
pnpm test
pnpm build       # 단계 마무리 시
```

하나라도 실패하면 완료가 아니다. 실패를 우회하려고 규칙을 끄거나 `// @ts-expect-error`, `eslint-disable`을 추가하지 않는다.

## 2. 수동 확인 (UI를 바꿨을 때)

변경한 기능에 해당하는 항목만 확인하고, 확인한 명세 ID를 보고에 적는다.

**시트 편집 (탭 1개)**

- [ ] 클릭·드래그·Shift+방향키로 선택 (S1)
- [ ] 바로 입력 / Enter·F2·더블클릭 이어서 편집 / Esc 취소 / Delete 지우기 (S2)
- [ ] 한글로 바로 입력 시작, 조합 중 Enter (S2 IME)
- [ ] 방향키·Enter·Tab·Shift 조합 이동, 가장자리, 화면 밖 스크롤 (S3)
- [ ] ⌘B·⌘I·⌘U·⌘⇧X, 범위 적용, 툴바 상태 (S4)
- [ ] ⌘Z·⌘⇧Z, 편집 모드 안의 ⌘Z (S5)
- [ ] 새로고침 후 유지, 모든 탭 닫고 다시 열기 (S6)
- [ ] 시트 목록에서 생성·열기, 없는 id (S8)

**공동 편집 (같은 시트를 탭 2~3개로)** — 2단계부터

- [ ] 새 탭 합류 시 최신 내용과 참여자 목록 (C1, C4)
- [ ] 한쪽 편집이 다른 탭에 즉시 반영 (C2)
- [ ] 같은 셀 동시 편집, 값+서식 동시 변경 (C3)
- [ ] 다른 탭 선택·편집 중 표시 (C5)
- [ ] 탭 닫기·새로고침·탭 복제 시 참여자 목록 (C6, C3)
- [ ] undo가 내 변경만 되돌림 (C7)

**AI (3단계)**

- [ ] 스트리밍 표시, 취소, 완료 후에만 적용 가능 (A3, A4)
- [ ] 적용 후 undo 1회 (A5)
- [ ] 네트워크 차단·키 오류 시 안내 (A6)
- [ ] 생성·검토 중 다른 탭 표시와 충돌 (X1~X3)

## 3. 보고 형식

```
검사: lint ✅ typecheck ✅ test ✅ (N개) build ✅/생략
수동 확인: S2, S3 확인 / S2-IME 미확인(이유)
남은 문제: 없음 | 목록
```

확인하지 않은 것은 "확인함"으로 쓰지 않는다.
